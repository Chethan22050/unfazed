# Unfazed

A therapist practice management SaaS platform designed to help therapists manage their practice, clients, appointments, sessions, communication, and subscriptions.

## 🚀 Features

- 🔐 Secure therapist authentication
- 👨‍⚕️ Therapist dashboard
- 👤 Client management
- 📅 Appointment and session management
- 💬 Communication features
- 📊 Practice management
- 💳 Subscription and entitlement management
- 🌐 Public therapist profile
- 📱 Responsive web interface

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Axios
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
